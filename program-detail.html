RoboExplorers: LEGO® SPIKE™ Prime & Autonomous Systems

The ultimate hands-on robotics pathway. Students design, engineer, and code autonomous machines using the official LEGO® Spike Prime hub, ultrasonic range sensors, dual smart motors, and Scratch block logic.

90 Mins / Weekly 8-Week Term Cohorts Max 6 Kids per Coach Master Builder Badge Certified

What Your Child Will Master

Every week features an engineering design challenge. Students start with a real-world problem (e.g. building an automated warehouse crane or a planetary explorer), sketch their mechanism, build the robot with Spike Technic beams, and write code to conquer the challenge.

Mechanical Principles

Gear reductions, torque vs speed, bevel gears, rack and pinions, and chassis integrity.

Coding Logic & Loops

Conditional logic (if/else), variables, broadcasts, while loops, and concurrent task threads.

Week-By-Week Syllabus

8-Week Project Curriculum

8 Sessions Total
Hardware unboxing, hub firmware, pairing via Bluetooth. Building the driving base chassis with dual drive motors and testing straight-line distance calculations.
Constructing gear trains: driver gear vs follower gear. Experimenting with uphill slope climbing to calculate maximum mechanical torque output.
Wiring the ultrasonic eyes. Coding robots to detect walls from 20cm away, stop safely, pivot 90 degrees, and navigate around random maze barriers.
Mounting the downward-facing color matrix. Writing proportional line-following code to trace curvy black tracks and stop at red intersection markers.
Building mechanical grabbers. Combining force sensors to pick up soda cans without crushing them and loading them into mobile hoppers.
Programming with the internal 6-axis gyroscope. Building two-legged walking mechanisms and measuring roll/pitch stabilization.
Reinforcing robot bumpers, optimizing gear ratio for maximum push power, and competing in friendly sumo ring matches.
Parents attend the final 30 minutes. Students demo their autonomous robot, present their design choices, and receive their physical & digital badge credential.

Learning outcomes

What Students Practice Along the Way

Each project connects a practical build with the engineering ideas behind it.

Plan a mechanism

Choose parts and explain how the moving pieces work together.

Write clear code

Use sequences, conditions, and repeatable tests to control a robot.

Use evidence

Observe sensor readings and adjust a design based on results.

Share a solution

Describe design choices and learn from other teams.

A Typical Session

Coach-led instruction leaves plenty of time for students to build and test.

01 · Brief

Explore the design challenge and key idea.

02 · Build

Assemble a first version with the class kit.

03 · Program

Make the robot respond to code or sensors.

04 · Improve

Test the result, make changes, and share.
